جلسه اول: ورود به دنیای سرور و خط فرمان

در این جلسه یاد می‌گیریم چگونه کدهای جاوااسکریپت را مستقیماً روی سیستم‌عامل (بدون مرورگر) اجرا کنیم و مقادیر داینامیک را به عنوان ورودی به آن‌ها بدهیم.

تمرین 01a.js مفهوم: process.argv

کد نوشته شده:
let x = process.argv;
console.log("input is:", x);

🛠 دستورات جدید این بخش:

  • process.argv: یک آرایه از تمام کلماتی است که هنگام اجرای فایل نود در خط فرمان وارد می‌کنیم.
  • console.log(): برای چاپ کردن خروجی و متغیرها در ترمینال یا کنسول استفاده می‌شود.
توضیح گام به گام و عمیق:

در دنیای Node.js ما شیءای جادویی و سراسری به نام process داریم که نمایانگر پروسه در حال اجرای این برنامه در سیستم‌عامل است. متغیر argv (مخفف argument vector) آرایه‌ای است از تمام کلماتی که هنگام اجرای برنامه در ترمینال تایپ کرده‌اید.

console.log(
    "sum is:",

🛠 دستورات جدید این بخش:

  • Number(): یک تابع داخلی جاوااسکریپت است که ورودی متنی (مثل "5") را به عدد واقعی (5) تبدیل می‌کند تا بتوانیم روی آن عملیات ریاضی انجام دهیم.
چه چیزی نسبت به قبل تغییر کرد؟

به جای چاپ کردن کل آرایه، مستقیماً به خانه‌های سوم و چهارم آرایه (ایندکس‌های 2 و 3) دسترسی پیدا کرده‌ایم و آن‌ها را با هم جمع می‌کنیم.

توضیح گام به گام و عمیق:

هر چیزی که از ترمینال وارد می‌شود، متنی (String) است. برای همین مدرس از تابع Number() استفاده کرده تا قبل از جمع کردن، ماهیت این ورودی‌ها را به اعداد تغییر دهد وگرنه جاوااسکریپت دو متن را به هم می‌چسباند (مثلا "5" + "10" می‌شود "510").

کد نوشته شده:
let command = process.argv[2];
let input = process.argv.slice(3);

console.log("------------------------");
console.log("command is:", command);
console.log("inputs are:", input);

//---------------------------------------------------------------------------------------

let controllers = [

        }
    },
    {
        name: "minus",
        func: function (input) {
            console.log("result is:", Number(input[0]) - Number(input[1]))
        }

        name: "print",

                name: input[0],
                email: input[1],

        }

]

//----------------------------------------------------------------------------------------

let found = false;
for(let i=0; i<controllers.length; i++){
    // console.log("index:",i);

  • for(let i=0; i<length; i++): حلقه تکرار برای پیمایش عناصر آرایه.
  • break;: برای متوقف کردن فوری و خروج از حلقه استفاده می‌شود (وقتی دستورمان را پیدا کردیم دیگر ادامه نمی‌دهیم).

توضیح گام به گام و عمیق:

هر عضو آرایه controllers یک آبجکت است که نام دستور و یک تابعِ بی‌نام (Anonymous function) دارد. در حلقه، چک می‌کنیم: آیا نام این کنترلر با دستوری که کاربر وارد کرده یکی است؟ اگر بله بود، بلافاصله تابع آن را اجرا می‌کنیم و با break از حلقه خارج می‌شویم. این دقیقاً هسته‌ی مسیریابی (Routing) در فریم‌ورک‌های وب است!

تمرین 04d (فایل‌های framework و app) آپدیت: استخراج هسته سرورمفهوم: Factory Function

کد 04d-framework.js (مغز فریم‌ورک پنهان):
import { createServer } from 'node:http';

function framework(){
    let controllers = [];
    let app = {
        get: function(path, func){
            controllers.push({
                name: path,
                func: func
            })
        },
        listen: function(port, userCallback){
            function serverCallback(request, response){
                console.log("------------------------");
                console.log("url: ", request.url);

                let found = false;

                for(let item of controllers){
                    if(request.url.startsWith('/' + item.name)){
                        found = true;
                        item.func(request, response);
                        break;
                    }
                }

                if(!found){
                    console.log("path not found.");
                }
            }
            let server = createServer(serverCallback);
            server.listen(port, userCallback);
        }
    }
    return app;
}

export { 
    framework 
}

    writeFile(items[2], items[3], function(error){
        if(error){
            console.log('error', error);
            response.writeHead(500);
            response.write("createFile error");
            response.end();
        }
        else{
            console.log(3);
            console.log("createFile done");

            response.writeHead(200);
            response.write("createFile done");
            response.end();
            console.log(4);
        }                
    });
});

app.get('readFile', function (request, response){
    let items = request.url.split("/");

    readFile(items[2], function(error, body){
        if(error){
            response.writeHead(500);
            response.write("readFile error");
            response.end();
        }
        else{
            console.log("readFile done");

            response.writeHead(200);
            response.write(body);
            response.end();
        }                
    });
});

🛠 دستورات جدید این بخش:

  • .push(): عنصری را به انتهای یک آرایه اضافه می‌کند. (استفاده در `app.get`)
  • app.get() و app.listen(): اینها متدهای سفارشی‌ای هستند که خود مدرس در شیء app تعریف کرده است تا استفاده از سرور برای برنامه‌نویسان راحت شود.
تغییر شگفت‌انگیز معماری:

کد اصلی ما (app.js) دیگر اثری از حلقه for و متد startsWith ندارد. اینجا یاد می‌گیرید که فریم‌ورک Express.js چطور کار می‌کند! متد app.get مسیرها را به آرایه مخفی پوش می‌کند و app.listen همان موتور مسیریاب را استارت می‌زند.

تمرین 04e-app.js آپدیت: تست قدرت فریم‌ورکمفهوم: ماژول fs.unlink

بخشی از کد جدید افزوده شده:
app.get('deleteFile', function(request, response){
    let items = request.url.split("/");
    unlink(items[2], function(error){ ... });
});

🛠 دستورات جدید این بخش:

  • unlink(): متدی از ماژول fs است که برای حذف (پاک کردن) یک فایل از روی سیستم استفاده می‌شود. (مانند writeFile رفتار ناهمگام دارد).
  • readFile(): فایلی را می‌خواند و دیتای آن را درون پارامتر دوم کالبک (به نام body) برمی‌گرداند تا به کاربر بفرستیم.
توضیح گام به گام و عمیق:

حالا که فریم‌ورک منعطفی داریم، اضافه کردن امکانات به برنامه بسیار راحت است. در این تمرین با متدهای readFile برای خواندن محتوا و unlink برای حذف فایل یک API ساده ساخته شده است که کاملا ناهمگام کار می‌کند.
